# Week 01

Codeforces 기초 문제를 풀며 시간 복잡도, 정렬, 구현과 C++ 기본 문법을 연습했습니다.

## 문제별 정리

### 4A - Watermelon

- 수박을 두 사람이 각각 양의 짝수 무게로 나눌 수 있는지 판단합니다.
- 전체 무게가 짝수이면서 `2`보다 커야 두 양의 짝수의 합으로 나눌 수 있습니다.
- 조건식에서 나머지 연산자 `%`를 사용해 짝수 여부를 확인합니다.

### 230A - Dragons

- 각 드래곤의 힘과 승리 보너스를 `pair<int, int>`로 묶어 `vector`에 저장합니다.
- 드래곤을 요구 힘이 낮은 순서로 정렬한 뒤 차례대로 상대하는 그리디 전략을 사용합니다.
- 현재 힘이 드래곤의 힘보다 반드시 커야 이길 수 있으며, 승리할 때마다 보너스를 누적합니다.
- 정렬 후 현재 상황에서 가장 약한 드래곤부터 상대하는 선택이 전체 성공 여부를 결정합니다.

### 231A - Team

- 세 팀원 중 두 명 이상이 풀이를 확신하는 문제의 수를 구합니다.
- 각 행의 `0`과 `1`을 더한 값이 `2` 이상인지 확인합니다.
- 조건을 만족할 때 정답 카운터를 증가시키는 단순 카운팅 방식입니다.

### 282A - Bit++

- `++X`, `X++`, `--X`, `X--` 형태의 문자열을 입력받습니다.
- 증가 연산 문자열이면 `x`를 1 증가시키고, 감소 연산 문자열이면 1 감소시킵니다.
- 문자열 전체를 해석하지 않고 증가 형태인지 비교하는 것만으로 연산을 구분할 수 있습니다.

### 339A - Helpful Maths

- `+`로 연결된 숫자 문자열에서 숫자만 추출해 `vector`에 저장합니다.
- 숫자를 오름차순으로 정렬한 뒤 숫자 사이에만 `+`를 출력합니다.
- 문자열 순회, 구분자 제외, 자료형 변환과 출력 형식 제어를 함께 연습할 수 있습니다.

### 405A - Gravity Flip

- 각 열에 쌓인 큐브 수를 `vector`에 저장합니다.
- 중력이 오른쪽으로 작용한 뒤의 상태는 각 열의 높이를 오름차순으로 정렬한 결과와 같습니다.
- 물리 과정을 직접 반복해서 시뮬레이션하지 않고 정렬로 최종 상태를 구합니다.

## 사용한 C++ 문법과 STL

- `if` / `else`: 조건에 따라 결과를 분기합니다.
- `for`: 초기화, 조건식, 증감식을 이용해 코드를 반복 실행합니다.
- `string`: 문자열을 저장하며 인덱스로 문자에 접근하거나 문자열을 비교할 수 있습니다.
- `vector`: 입력 크기에 맞춰 값을 동적으로 저장합니다.
- `pair`: 서로 연관된 두 값을 하나의 묶음으로 저장하고 관리할 때 사용합니다.
- `sort`: 지정한 범위의 원소를 기본적으로 오름차순으로 정렬합니다.
- `%`: 두 정수를 나눈 나머지를 구하며 배수나 홀짝을 판별할 때 활용합니다.
